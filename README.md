# Basket Random — 本地直接游玩版

**双击 `index.html` 就能玩**，不需要启动服务器、不需要联网、不需要安装任何东西。
`index.html` 是一个自包含的 HTML 文件，可以单独复制到 U 盘、其它电脑上直接运行。

## 快速开始

1. 用 Chrome / Edge（较新版本）打开 `index.html`。
2. 启动画面显示「数据线」，约 2 秒后淡出，不拦截点击。
3. 在标题画面选择 **1P** 或 **2P** 开始。
4. 右上角 **⚙** 打开设置，或按 **F2**；**Esc** 关闭设置。

### 操作

| 模式 | 操作 |
| --- | --- |
| 1P | `W` / `空格` / 点击画面起跳 |
| 2P | 左玩家 `W`，右玩家 `↑`（上方向键） |

原版规则是**先得 5 分获胜**；开启无限模式后不设分数上限。

## 设置功能

点击右上角齿轮或按 `F2` 打开设置面板：

| 设置 | 说明 |
| --- | --- |
| **界面语言** | 中文 / English。设置面板、比分板、球类型提示、帧率单位、操作提示全部随之切换 |
| **画质** | 流畅 0.75x / 标准 1x / 高清 1.25x / 超清 1.5x。实际改变 canvas 渲染分辨率（如 0.75x 时从 934×547 变为 701×410），低档更流畅、高档更清晰 |
| **画面平滑** | 关闭为像素风（`image-rendering: pixelated`），开启为平滑缩放 |
| **音量 / 静音** | 0–100% 滑块，直接调节游戏主增益 |
| **左上角帧率显示** | 可开关的 FPS 计数器，中文「帧/秒」、英文「FPS」 |
| **解除帧率限制** | 绕过垂直同步，用高频定时器驱动渲染；物理参数仍按显示器真实刷新率计算，不会被加速 |
| **无限模式** | 取消 5 分上限，比赛永不结束，累计比分无上限增长 |
| **比分左右对调** | 修正项目内部 `p1Score/p2Score` 与画面左右方向相反的问题；如觉得方向不对可随时取消勾选 |
| **显示比分板** | 顶部中央的中英比分板 |
| **显示球类型提示** | 显示每局球类型的中文／英文名称 |
| **抛物线辅助** | **长按投篮键就显示**预测抛物线、力度与命中点（左方 `W`/空格、右方 `↑`），按多久都有效，松开立即消失；还没拿到球时线会变淡并附一行状态提示 |
| **长按屏幕也能自瞄** | 默认开启。**长按游戏画面 250ms** 即激活自瞄：左半屏 = 玩家1（投右筐），右半屏 = 玩家2（投左筐）；单击（<250ms）不会触发，不影响正常点击起跳；可在设置里关闭 |
| **投篮力度 / 弧线** | 0.5–2.0，决定抛物线飞行时间（力度越大弧线越平），抛物线辅助与自瞄共用 |
| **球类型名称（可自定义）** | 展开后 4 个输入框，可自己改名字，即时生效并保存；同时实时显示当前游戏动画名 |
| **全屏 / 重新开始** | 切换浏览器全屏；一键重载 |
| **自动保存** | 全部设置存在浏览器本地（localStorage） |

切换**语言 / 画质 / 无限模式**需要重建游戏，会自动重新开始一局；其余设置即时生效。
设置面板是浮层，面板以外区域照常游戏，操作不会穿透到游戏里。

### 球类型提示

游戏里真正可见的球是 `ballLine` 对象，它的**动画名**就是球类型：
`ball` / `heavy` / `kames` / `smallball`。
（`heavyBall`、`normalBall` 等对象只是常驻的不可见物理碰撞体，不能用来判断球类型。）

默认中文名称与颜色对照：

| 动画名 | 默认名称 | 说明 |
| --- | --- | --- |
| `smallball` | 弹力球 | 紫色 |
| `kames` | 双倍球 | 彩色 |
| `heavy` | 铅球 | 灰色 |
| `ball` | 普通球 | 普通篮球 |

**名称可以自己改**：设置 → 「球类型名称（可自定义）」，展开后直接编辑 4 个输入框，
左边就是内部动画名，上方实时显示当前局的动画名，方便一一对照。

## 管理员菜单（Alt + 6）

仅作用于这份本地离线单机版。打开方式有 **3 种**：

- 按 **Alt + 6**（再按一次关闭）
- 在 ⚙ 设置面板底部**连点「数据线」3 次**（2 秒内）
- 彩蛋与快捷键都只是显隐面板，不改变任何设置

关闭方式同样有 **3 种**：标题栏 **×**、面板底部**「关闭菜单」按钮**、**Esc**。
标题栏可拖动，**双击标题栏**把面板复位到默认位置（避免拖到屏幕角落找不回来）。

**面板只是界面，不是功能开关**：关闭菜单后方框 / 骨架 / 距离线等绘制层与自瞄、抛物线辅助都继续运行。
绘制画布独立于面板 DOM，绘制循环也不再受面板显隐影响。
首次启动画面保持干净（没有任何常驻覆盖元素）；**第一次按 Alt+6 之后**绘制层即长期启用（跨会话保存），
想彻底关掉可在菜单第一行取消「启用绘制层（关闭菜单后仍保持）」。

| 分组 | 功能 |
| --- | --- |
| **绘制 / OVERLAY** | 第一行是**「启用绘制层（关闭菜单后仍保持）」总开关**；**方框**：给 4 名球员、球、2 个篮筐画彩色矩形（左侧青、右侧橙、球黄、筐紫）；**骨架**：连接头/身体/手臂/碰撞体的连线与关节点；**距离线**：球到每名球员/篮筐的虚线并标注距离；**名称标签**；**瞄准线**；线宽滑块 |
| **自瞄 / AUTO SHOT** | **长按投篮键或长按屏幕即激活**（左方 `W`/空格，右方 `↑`；屏幕左半屏=玩家1、右半屏=玩家2，按住 250ms）。激活期间持续待机，**只有真正拿到球**（游戏判定 `hold=1`）才起投：球在空中、落地、对面手上时不投、不加分，只显示等待提示。球停在地上或悬在中场等开球时，辅助会把球递到本方球员手上（由**游戏自己**判定持球），形成「拿到球 → 投 → 回手 → 再投」的循环。投篮方由输入决定，默认投对侧筐，也可固定左/右筐 |
| **校准 / CALIBRATION** | 缩放、X/Y 偏移滑块，用于微调覆盖层与游戏画面的对齐 |
| **状态 / STATUS** | 实时 FPS、球坐标、球类型、最近球员与距离、制导帧数 |

### 触发规则与弹道说明

「拿到球」用的是游戏自己的状态：`hold=1`、`who=持球手臂编号`、`handCollision=1`、
对应 `armN.instVars.have=1`。**只有这个状态为真才会起投**，不会出现「球还在空中就自动投篮」：

- **长按不超时**：`W` / `↑` / 空格按住期间一直激活，只由松键、窗口失焦、页面隐藏结束；
- **长按屏幕**：按住游戏画面 250ms 激活（左半屏玩家1、右半屏玩家2）；
  单击（<250ms）不触发，不影响正常点击起跳；可在设置里关闭；
- **抛物线辅助**：激活时就画预测线，还没拿到球时线变淡 + 一行等待提示；
- **严格拿球才起投**：球在空中、落地、对面手上时只待机；持球方必须与投篮方一致；
  另留 150ms 余量容忍低帧率（视觉上球仍贴在手边），审计记录区分「本方持球 / 刚拿到球」；
- **递球循环**：进球后球回到本方球员的**手部碰撞体**；球停在地上、或悬在中场等开球时，
  每 0.7 秒把球递到本方球员手上 —— 由**游戏自己**判定 `hold=1` 后辅助才起投，不直接加分；
- **投篮方由输入决定**：`W`/空格 = 玩家1 投右筐，`↑` = 玩家2 投左筐；
  两键齐按才按球所在半场判断，目标不会因球跨半场而跳变；
- **起投先松手 / 解锁**：球被抓着就清 `hold` / `have` / `who` 并重新启用物理，
  否则 `teleport` 完全无效；
- **一次投篮一条路径**：起投时生成 72 个抛物线路径点（水平线性、垂直拱起），
  绘制与制导共用；每帧把球 `teleport` 到路径点并把速度归零，
  避免两帧之间按旧速度继续跑造成偏离。画出来的线就是球真正走的路。

游戏内部得分还依赖 `goal` 状态机，因此**命中时由本地辅助直接写入分数**并同步原生计分板。
稳态制导误差约 10 布局像素（headless 软件渲染低帧率下的帧间漂移，正常 GPU 更小）。
因物理碰撞与随机球/篮筐变化，仍不承诺数学意义上的 100%。
想长时间连投建议开启**无限模式**，否则游戏 5 分就结算。

实测（Edge headless，file://）：长按 12 秒 **7 投 6 中，7 次起投全部 `hold=1`**；
长按屏幕 4 秒 **3 投 3 中**；未长按 / 按错方向时 0 起投、0 加分；0 异常、0 外网请求。

覆盖层用独立 canvas 绘制，读取 C3 运行时的实例坐标（布局 290×190 → canvas 线性变换，实测对齐）。
面板本身可拖动，其余区域照常游戏，绘制不拦截输入。
设置保存在 localStorage。**面板界面**默认隐藏（每次按 Alt+6 或三击彩蛋打开），
但**绘制层与功能开关**在首次打开过菜单后就与面板显隐无关，关闭面板照常运行。

### 无限模式怎么工作

双保险，确保「打到 5 分也不会结束」：

1. 加载一份单独处理过的项目数据，把项目内的结算函数置空；
2. 运行时在游戏达到胜利阈值之前把内部分数回绕，同时把真实得分累计到独立计数器。

顶部比分板显示**累计真实比分**（可无限增长），原生位图计分板在无限模式下隐藏，避免两套数字冲突。
标准模式保持原版规则不变。

### 关于中文翻译

游戏里的标题、`1P`/`2P`、`HOLD W` 等是**位图图片**，没有中文字形，无法直接改写。
因此中文功能采用「界面 + 术语」的方式实现，不在画面上叠加固定的图片标注（避免遮挡和误标）：

- 设置面板、比分板、帧率、操作提示完整中文化并可切回英文；
- 每局球类型用中文提示显示（读取运行时真实状态）；
- 「数据线」只出现在**启动画面**和**设置面板底部**，无常驻水印。

## 修复了什么（相对原始导出）

原目录是从 CrazyGames 抓取的 **Construct 3 导出残件**，直接双击 `index.html` 会失败：

| 问题 | 处理方式 |
| --- | --- |
| 缺 `data.json`、`box2d.wasm`、33 张图片、16 个音频、2 个 worker 脚本 | 从官方资源托管补齐，共 54 项资源 |
| `file://` 下 ES module / 动态 `import()` 被 CORS 拦截 | 所有 JS 内联；运行时入口改为注入内联代码包 |
| `file://` 下 `fetch` 相对资源被禁止 | 内置虚拟资源层，用 base64 拦截并提供全部资源 |
| `file://` 下 `new Worker(...)` 无法加载 | worker 源码转为 `blob:` URL |
| 原页面 `file://` 警告弹窗、ServiceWorker 注册、BroadcastChannel | 移除 |
| 外部 CrazyGames 广告 SDK、Google 广告脚本 | 移除并替换为无广告的空实现，跳过广告不卡关 |
| 老显卡（Intel Gen7/Gen9 等）WebGPU 探测报红错再回退 | 运行时里直接关闭 WebGPU 探测，稳定使用 WebGL 2 |

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | **成品**，自包含单文件（约 3.8 MB），直接双击游玩 |
| `index.source.html` | 原始 HTML 壳备份 |
| `scripts/`、`project/`、`box2d.wasm.js`、`style.css`、`appmanifest.json` | 原始导出源码，保留供参考；成品运行不依赖它们 |
| `.work/` | 下载的资源、构建脚本与验证脚本，用于复现构建 |

重新生成成品：

```bash
node .work/build.js          # 生成 index.html
node .work/check-syntax.js   # 校验内联脚本语法
node .work/cdp-final.js      # 用 Edge headless 以 file:// 全面实测
node .work/cdp-gate.js       # 严格拿球 / 按键对应 / 起投审计 / 命中计分
node .work/cdp-longhold.js   # 长按 12 秒全程有效、无 4 秒超时、连续投篮
node .work/cdp-touch.js      # 长按屏幕自瞄、单击不误触、关开关后失效
node .work/cdp-persist.js    # 关闭菜单后绘制与自瞄仍运行、启动画面干净
node .work/quick.js          # 快检球类型自定义、水印、控制台
```

构建相关源码：`.work/build.js`（打包）、`.work/offline-ext.js`（运行时扩展）、
`.work/settings.css` / `.work/settings.html` / `.work/settings.js`（设置面板）、
`.work/admin.css` / `.work/admin.html` / `.work/admin.js`（管理员菜单）、
`.work/trajectory.js`（抛物线辅助与自瞄制导）。
构建只读原始源码 + `.work/assets/` 与 `.work/data.json`，不改动任何原始文件。

管理员菜单专项验证：`node .work/cdp-final2.js`
（拖动/三种关闭/三击彩蛋/松手清除/异常检查）。

专项验证：
- `node .work/cdp-gate.js`：**未长按 / 按错方向时 0 起投 0 加分**、
  由弹道模块直接记录的**每次起投原因**（`hold` / `heldAgo`）、松开后画布清空、异常与外网请求；
- `node .work/cdp-longhold.js`：长按 12 秒逐帧统计 `active` / 抛物线常亮比例、
  起投明细全部 `hold=1`（验证没有超时失效、也不是「没拿到球就投」）；
- `node .work/cdp-touch.js`：单击 120ms 不激活、长按左/右半屏识别正确、
  长按期间起投全部持球、关闭开关后长按无效；
- `node .work/cdp-persist.js`：启动画面干净、Alt+6 后绘制出现、关闭面板后仍持续绘制、
  关闭面板状态下长按屏幕仍可自瞄、总开关可彻底关闭绘制。

## 环境要求与控制台说明

- Chrome / Edge 等现代浏览器，需支持 WebGL 与 WebAssembly。
- 首次播放声音需要一次点击或按键（浏览器自动播放策略，游戏已内置解锁逻辑）。
- `file://` 下可能看到 `navigator.cookieEnabled` 的兼容性提示，以及切换窗口时的
  `[Construct] Suspending / Resuming`，都是浏览器/引擎的正常行为，不影响游玩。
- `[C3 advert] Event (configuration complete ...)` 是离线广告替身的日志，无广告、无外网请求。
